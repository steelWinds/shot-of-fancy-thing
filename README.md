# Shot of Fancy Thing

Nuxt 4 app with pnpm, Tailwind CSS 4, Nuxt Content, i18n and Pinia Colada.

## Setup

```bash
pnpm install
```

## Development

```bash
pnpm dev
```

## Production

```bash
pnpm build
pnpm preview
```

The Docker image uses the same pnpm lockfile:

```bash
make build
make run
```
